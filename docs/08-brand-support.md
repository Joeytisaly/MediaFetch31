# TCPGYT 品牌与捐赠占位（Brand & Support v0.1）

**状态：草案（待审批）**
**关联：** `docs/00-project-charter.md`（§1 身份、§5 专项约束）、`docs/01-prd.md`（§5.6、验收 10/11）、`docs/05-data-model.md`（§2.9）、`docs/07-test-acceptance.md`（§6）

> 本文件定义品牌资产与捐赠信息的**集中配置槽位**与降级行为,确保「替换不改业务、未配置不出失效入口」。
> 全部为可替换占位;真实 URL / 二维码 / 图片资源由用户提供后填入,不在文档内硬编码任何外链。

## 0. 原则（章程 §1/§5、PRD §5.6）

- **集中配置**:Logo、应用图标、应用名、捐赠 URL、捐赠二维码、开发者信息集中在配置对象,**禁止散落硬编码**。
- **替换不影响业务**:改这些值不得影响下载/文件/设置逻辑(验收 11)。
- **未配置即降级**:捐赠信息未配置时,隐藏入口或显示不可点击「暂未开放」,**不得出现失效链接**(验收 10)。
- **无远端**:品牌/捐赠不引入任何统计、追踪或回传(章程 §1)。

## 1. 配置模型（对齐 05 §2.9）

| 键 | 类型 | 默认/未配置行为 | 来源 |
|---|---|---|---|
| `brand.appName` | String | 默认 `TCPGYT` | 章程 §1 |
| `brand.logo` | 资源引用 | 统一视觉占位,不影响布局 | 用户提供 |
| `brand.appIcon` | 资源引用 | 默认占位或系统安全回退 | 用户提供 |
| `developer.name` | String | `TCPG007014 (YaR)` | 章程 §1 |
| `developer.email` | String | `ChengYuan.tcpg@gnail.com` | 章程 §1 |
| `support.donationUrl` | String? | 未配置 → 隐藏入口 / 「暂未开放」不可点击 | 用户提供 |
| `support.donationQrCode` | 资源引用? | 未配置 → 不渲染 | 用户提供 |

> 固定身份值(appName / developer.*)来自章程,视为不变量;`support.*` 与图片资源为待填占位。

## 2. 展示位与降级（对齐原型「更多 › 关于与支持」)

| 展示位 | 已配置 | 未配置(降级) |
|---|---|---|
| 关于页 App 头(logo + appName) | 显示品牌 logo + 名称(左对齐横排,见 PROGRESS §4) | 占位图 + 默认名 `TCPGYT` |
| 开发者信息 | name + email | 恒有(章程固定值) |
| 捐赠入口 | 可点击 → 打开 `donationUrl` | 隐藏 或 「暂未开放」不可点击 |
| 捐赠二维码 | 渲染 `donationQrCode` | 不渲染,不留空占位框 |

- 捐赠外链点击前,可给出「即将离开应用/跳转外部页面」的告知 **[待审批]**(体验项)。

## 3. 硬约束（不得违反）

- 不在代码/文档中硬编码任何真实捐赠外链或第三方地址;一律走 `support.*` 配置。
- 捐赠功能不得携带用户标识、下载记录或任何遥测参数(章程 §1)。
- 未配置时**绝不**渲染失效链接或空跳转(验收 10)。
- 品牌资源替换仅改配置与资源文件,不触碰下载/任务/存储逻辑(验收 11)。

## 4. 验收对应（见 07 §6）

- T-BRAND-01:捐赠未配置 → 入口隐藏/「暂未开放」,无失效链接(验收 10)。
- T-BRAND-02:替换 logo/appIcon/appName → 业务不受影响,未配置走安全占位(验收 11)。
