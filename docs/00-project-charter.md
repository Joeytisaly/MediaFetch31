## 1. 项目定义

TCPGYT 是面向 Android 的本地优先音视频下载与下载管理产品。用户提交经授权的公开资源链接，应用解析可用格式，创建下载任务，并提供进度、文件和失败状态管理。

当前 Figma Make/React 工程用于产品需求沉淀、Android 交互原型、接口契约展示与联调模拟。未来 Android 原生工程和下载引擎须作为边界清晰的独立模块建立。

## 2. 产品目标

1. 提供清晰、安全、可追踪的下载任务体验。
2. 在提交任务前展示可用格式、清晰度、容器和预计文件大小。
3. 为任务提供待解析、排队、下载、暂停、后处理、完成、失败、取消等明确状态。
4. 预留可替换的 Logo、应用图标、捐赠入口和开发者信息。
5. 建立先审后写的受控开发流程。
6. 让技术依赖具备可核查来源、版本依据、兼容性说明和回滚策略。

## 3. 硬性边界

- 不建设用于注册、账号、用户画像、下载记录或个人数据收集的远程服务器。
- 不提供注册、登录、云端用户档案、云同步或用户行为分析。
- 下载解析、任务执行、文件保存、历史记录和应用配置默认在用户设备本地完成。
- 仅支持用户有权下载的公开资源或用户拥有合法访问权限的资源。
- 不实现或协助绕过 DRM、付费墙、验证码、访问控制或平台安全机制。
- 当合法访问的资源需要兼容时，可提供默认关闭、用户主动启用的本地 Cookie 导入功能。Cookie 仅保存在设备受保护存储中，不上传、不共享、不用于追踪，并且可由用户删除或清空。

1. 未获得用户明确批准，不得创建、修改、删除或重命名项目文件，不得安装依赖。
2. 每项业务、技术、依赖、品牌和数据处理决策都必须先提交审核。
3. 每次写入申请必须列出文件路径、修改原因、关联影响、回滚方式和验收标准。
4. 大型功能必须拆分为可验收切片；不得只实现界面而缺失状态、异常处理、接口契约或测试要求。
5. 依赖必须具备官方文档、GitHub Release、Maven Central、npm 或 PyPI 等可验证依据，并记录许可证和兼容性。
6. 可研究公开项目的架构与交互，但不得复制与本项目许可证不兼容的代码。
