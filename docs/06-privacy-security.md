# TCPGYT 隐私与安全合规（Privacy & Security v0.1）

**状态：草案（待审批）**
**关联：** `docs/00-project-charter.md`（§1 不变量、§5 专项约束）、`docs/01-prd.md`（§3.3 隐私）、`docs/02-architecture.md`（ADR §5）、`docs/04-api-contract.md`（§4 CookieVault）、`docs/05-data-model.md`（§2.7）

> 本文件把章程/PRD/ADR 中分散的隐私与安全硬约束,收敛为可执行、可验收的一份基线。
> 一切以**本地优先、无远端、最小暴露**为原则。凡涉及尚未拍板的实现细节,标 **[待审批]**。

## 0. 安全原则（不变量,不可协商）

- **本地优先**:解析、任务、文件、设置、历史默认仅在用户设备本地处理(章程 §1)。
- **无远端**:不建服务器,不注册/登录/上传个人信息,无云同步/行为分析/远程日志(章程 §1)。
- **最小暴露**:敏感数据只在必要范围、必要时长内存在,用后即清。
- **不绕过**:不实现 DRM / 付费墙 / 验证码 / 访问控制绕过(章程 §1)。
- **仅授权资源**:仅支持用户有权访问和下载的资源(章程 §1)。

## 1. 敏感数据清单与生命周期

| 敏感数据 | 存放 | 生命周期 | 禁止 |
|---|---|---|---|
| Cookie 明文 | **仅内存**,用户主动导入时临时持有 | 供引擎单次请求取用,用后立即清内存 | 落 Room 普通表 / SharedPreferences / 日志 / 通知 / 分享 / 崩溃报告 / 异常堆栈(章程 §1、PRD §3.3、ADR §5) |
| Cookie 密文 | 安全私有存储(`CookieSecret`),Keystore 密钥加密 | 用户删除即销毁,删除后引擎不可再读 | 与元数据混存;导出/上传/同步 |
| Cookie 元数据 | Room(`CookieEntry`,仅来源标识/时间/密钥别名) | 随条目删除 | 含任何明文片段 |
| 原始 URL(含 token/授权参数) | **不落库** | 仅解析瞬时使用 | 持久化;`DownloadTask` 只存脱敏 `sourceUrlDisplay` + 无凭据的 `sourceRef`(05 §2.1) |
| 授权头 | **不落库/不记录** | 仅请求瞬时 | 任何持久化或日志 |

## 2. Cookie 本地兼容功能（章程 §1/§5、ADR §5、PRD 验收 9）

- **仅用户主动启用**:设置页显式开关,默认关闭。
- **仅本地导入**:用户主动选择文件导入;**禁止**浏览器/WebView 自动抓取。
- **导入前告知**:用途、风险、"仅本地保存"、删除方式(PRD §5.4)。
- **加密隔离**:密文经 Keystore 密钥加密,与元数据分离存储(05 §2.7)。
- **取用受限**:仅引擎适配层在用户请求时经 `CookieVault.readForRequest(ref)` 临时取用,用后清内存(04 §4)。
- **可删除**:`deleteOne` / `clearAll`;删除后引擎不可再读(验收 9)。
- **降级安全**:若 Keystore 无法安全初始化 → 禁用 Cookie 功能,**不回退明文**(ADR §5)。
- Cookie 文件支持格式与 `import` 校验字段 **[待审批]**(PRD §8-3)。

## 3. 本地存储与加密

- 分区严格按 05 §1:Room 私有库(非敏感) / 安全私有存储+Keystore(密文) / DataStore(偏好、品牌,无凭据) / MediaStore(用户媒体本体)。
- Room / DataStore 位于应用私有目录,随系统沙箱保护;**不存任何凭据**。
- 加密支撑库(如 `androidx.security-crypto`)与 Keystore 具体方案 **[待审批]**(工具链/架构落地阶段,见 03 §5)。

## 4. 日志与诊断脱敏

- **禁止**打印:Cookie 明文、授权头、完整原始 URL(含 query 凭据)。
- 失败信息只用 `FailureCode` + 已脱敏 `failureNote`(05 §2.1/§2.5、04 §1);不得把引擎原始异常(可能含 URL 参数)直接透传到 UI/日志。
- 无远程/崩溃上报 SDK(章程 §1);本地诊断日志(若有)同样适用上述脱敏规则。

## 5. 网络边界

- 网络访问仅限:①解析/下载目标资源本体;②(可选)缩略图。
- **无**任何指向本项目自有服务端的请求(无遥测/统计/账号/更新拉取)。
- 下载须经引擎适配层(04 §1),UI/ViewModel 不得直接发起下载命令或自由网络调用(ADR §3/§8-8)。

## 6. 删除与清理策略（对齐原型「本地数据」+ 文件操作）

明确区分三类删除,不得混淆(章程 §5):

| 操作 | 影响 | 说明 |
|---|---|---|
| 删除任务记录 | 仅移除 `DownloadTask` + 关联 `StatusTransition` | 不动用户媒体文件(04 §3 `deleteRecord`) |
| 删除临时文件 | 清理未完成/缓存/缩略图 | 不动已完成媒体 |
| 删除用户媒体文件 | 删 MediaStore/文件本体 | **须二次确认**(04 §5 `deleteFile`) |
| 清空 Cookie | 销毁密文 + 元数据 | 删除后引擎不可再读(验收 9) |

## 7. 威胁与缓解（要点）

| 威胁 | 缓解 |
|---|---|
| Cookie 明文泄漏(日志/崩溃/分享) | 明文仅内存+用后清;全链路脱敏(§1、§4) |
| 密钥/密文被离线读取 | Keystore 密钥 + 密文隔离;无法安全初始化则禁用(§2) |
| 敏感 URL 参数落库/上报 | 只存脱敏展示串;不落原始 URL/授权头(§1) |
| 越权/绕过滥用 | 不实现任何 DRM/访问控制绕过;仅授权资源(§0) |
| 供应链(GPL 依赖二进制) | 依赖来源核验 + 许可合规(见 03) |
