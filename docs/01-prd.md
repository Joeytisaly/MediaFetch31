# TCPGYT 产品需求文档（PRD v0.1）

**状态：已批准**  
**产品名称：** TCPGYT  
**目标平台：** Android  
**开发者：** TCPG007014 (YaR)  
**联系邮箱：** ChengYuan.tcpg@gnail.com

## 1. 产品概述

TCPGYT 是一款 Android 本地优先的音视频下载与下载管理应用。用户安装后无需注册或登录，即可粘贴自己有权访问和下载的公开资源链接，查看可用格式并创建本地下载任务。

应用不建立用于收集用户数据的服务器，不提供账号体系、远程用户档案、云端下载历史或行为分析服务。解析、下载、文件保存、任务记录和应用配置都在用户设备上完成。

当用户对某些资源拥有合法访问权限且确有兼容需要时，应用可提供默认关闭、用户主动启用的本地 Cookie 导入功能。该凭据仅保存在设备受保护区域，不上传、不共享、不用于用户追踪；用户可随时删除。

## 2. 目标与成功标准

### 2.1 目标

1. 无账号完成从链接到本地文件的完整下载流程。
2. 下载前展示标题、时长、格式、清晰度、容器和预估文件大小。
3. 提供进度、状态、失败原因、取消和重试能力。
4. 将完成文件保存至 Android 系统可访问位置，并允许从应用打开或定位文件。
5. 预留可替换的 Logo、应用图标、开发者信息和捐赠信息占位。
6. 确保本地凭据和下载记录不离开用户设备，除执行用户主动请求所必需的目标资源网络请求外。

### 2.2 首版成功标准

- 新用户可在无账号状态下完成一次受支持、已授权的公开资源下载。
- 解析失败、网络失败、存储不足、格式不可用和用户取消均有状态与恢复建议。
- 用户可暂停、恢复、取消或删除任务。
- 用户可打开文件或查看文件位置。
- Cookie 功能默认关闭，并具备启用、导入、查看、删除和清空流程。
- 未配置捐赠信息时不显示无效链接或空白交互。

## 3. 合规、内容与隐私

### 3.1 允许范围

- 用户自己发布或拥有版权的内容。
- 平台或版权方明确允许下载的公开内容。
- 用户拥有合法访问权限且平台允许在该权限下获取的内容。

### 3.2 不支持范围

- 绕过 DRM、加密媒体保护、付费墙、验证码或平台访问控制。
- 规避平台服务条款、版权限制或其他安全机制。
- 收集、上传或出售下载记录、Cookie、设备标识或个人资料。
- 账号注册、社交登录、云端同步、远程用户档案、用户行为分析。
- 未经审核的远程代理、转码服务或下载中转服务器。

### 3.3 Cookie 规则

| 规则 | 要求 |
|---|---|
| 默认状态 | 关闭，不要求用户提供 Cookie。 |
| 启用前提示 | 说明用途、风险、本地保存方式和删除方法。 |
| 导入方式 | 首版建议仅支持用户选择本地 Cookie 文件导入；其他方式需单独评审。 |
| 存储位置 | Android 加密/受保护应用私有存储。 |
| 网络行为 | 仅随用户主动发起的目标资源请求使用；不得上传到项目自有服务器或第三方分析服务。 |
| 控制能力 | 显示来源标识和最后使用时间；支持单项删除、覆盖导入和全部清空。 |
| 日志 | 不记录完整 Cookie、授权头或敏感 URL 参数。 |

## 4. 用户与核心流程

### 4.1 目标用户

- 希望直接粘贴公开链接并保存视频或音频的 Android 用户。
- 希望选择清晰度、音频码率或容器格式的用户。
- 已合法登录目标平台，需要在本机导入自身 Cookie 才能兼容部分资源的用户。

### 4.2 主流程

1. 用户打开首页。
2. 粘贴或输入 URL。
3. 系统做基础 URL 校验并解析资源。
4. 用户查看标题、封面、时长、来源和可用格式。
5. 用户选择音频或视频格式并创建下载任务。
6. 下载队列显示进度、速度、预计剩余时间和状态。
7. 完成后，用户打开文件或定位保存目录。
8. 失败时，用户查看原因并重试或移除任务。

## 5. 功能需求

### 5.1 首页

- 展示 Logo 占位和产品名 TCPGYT。
- URL 输入、手动输入和粘贴能力。
- 简短合规提示。
- 剪贴板含基础 URL 时显示“粘贴并解析”。
- 提供下载任务、设置、关于与支持入口。
- 空链接禁用解析；无效 URL 提示；网络不可用时保留输入。
- 相同资源和相同格式已有任务时提示查看现有任务或新建任务。

### 5.2 解析与格式选择

- 展示封面、标题、来源、时长。
- 提供视频/音频类型与可用格式。
- 格式显示清晰度或码率、容器、编码摘要、预估大小或大小未知。
- 默认推荐格式必须有可解释理由。
- Cookie 可能改善兼容性时，只显示非强制提示和设置入口。
- 用户选择格式并确认创建任务。
- 不可访问、无格式或格式失效时显示明确错误与返回操作。

### 5.3 下载队列

状态机：

```text
待解析 → 可选择格式 → 排队中 → 下载中 → 后处理中 → 已完成
                        ↘ 已暂停 ↔ 下载中
任意非终态 → 已取消
任意执行态 → 失败 → 可重试 / 删除
```

每项任务显示标题、缩略图、状态、进度、大小、速度、剩余时间、选择的格式和时间信息。支持：

- 下载中：暂停、取消。
- 已暂停：继续、取消。
- 失败：重试、删除、查看失败详情。
- 已完成：打开文件、查看位置、删除记录、删除文件（需二次确认）。
- 排队中：取消。

Android 实现阶段需使用合规的前台下载服务和通知栏状态。后台、锁屏或应用切换时不得丢失任务状态；系统杀死后的恢复策略必须另行审核。

### 5.4 文件库与历史

- 分类：下载中、已完成、失败、已取消。
- 按状态筛选。
- 打开文件、打开文件位置、删除任务记录。
- 删除时区分“只删记录”和“同时删除设备文件”。
- 完成文件保存到用户可理解、可访问的 Android 媒体或下载目录。
- 任务元数据、应用偏好和 Cookie 保存在应用私有存储。

### 5.5 设置

- 默认下载类型：视频/音频。
- 默认清晰度或音频质量：自动/可用选项。
- 下载网络偏好：任意网络/仅 Wi-Fi。
- 保存位置显示与修改（受 Android 存储策略约束）。
- 清理历史记录与临时缓存。
- Cookie 管理。
- 关于与支持。

Cookie 管理页应包含：启用状态、导入 Cookie 文件、已导入来源列表、覆盖导入、删除单项、清空全部及安全说明。

### 5.6 关于、支持与品牌占位

固定信息：TCPGYT、TCPG007014 (YaR)、ChengYuan.tcpg@gnail.com、版本占位、开源许可与第三方声明入口占位。

可替换配置：

| 标识 | 初始行为 |
|---|---|
| `brand.logo` | 统一视觉占位，不影响布局。 |
| `brand.appIcon` | 默认占位资源或系统安全回退。 |
| `brand.appName` | 默认值为 TCPGYT。 |
| `support.donationUrl` | 未设置时隐藏主操作或显示暂未开放。 |
| `support.donationQrCode` | 未设置时不渲染。 |
| `developer.name` | TCPG007014 (YaR)。 |
| `developer.email` | ChengYuan.tcpg@gnail.com。 |

## 6. 非功能需求

### 隐私与安全

- 不接入行为分析 SDK、广告 SDK 或上传型崩溃日志服务，除非后续单独审批。
- 不在日志、错误信息或任务历史中保存 Cookie 明文。
- 敏感信息不得出现在分享内容、通知栏或截图预览中。
- Cookie 删除后必须无法再被下载引擎读取。

### 可用性

- 首页主操作应一屏可见。
- 状态不能只用颜色表达，必须有文字或图标语义。
- 破坏性操作必须确认。
- 空状态、加载、无网络、解析失败和存储不足均需对应界面。

### 性能与稳定性

- 不允许无上限并发下载；并发策略待架构阶段确定。
- 大文件断点续传能力必须在技术验证阶段确认。
- 下载不应阻塞 UI 线程。
- 错误摘要应可诊断但不得泄露敏感信息。

## 7. 验收用例

1. 有效公开链接能显示资源和格式列表。
2. 选定视频格式后任务可进入队列并开始下载。
3. 下载可暂停、恢复、取消，状态持久化正确。
4. 网络中断显示失败并允许重试。
5. 存储空间不足不产生假完成状态。
6. 完成后可打开或定位文件。
7. 不导入 Cookie 也可使用公开资源流程。
8. Cookie 可导入、单项删除和全部清空。
9. Cookie 内容不出现在任务列表、错误信息或普通日志。
10. 未配置捐赠地址时不出现失效跳转。
11. 替换品牌或捐赠配置无需改动下载业务逻辑。
12. 首次启动、无任务、无网络和空历史都有明确状态。

## 8. 后续待决策项

3. Cookie 文件的支持格式与安全校验。
4. 默认并发数、断点续传和任务恢复策略。
5. Android 保存策略与权限。
6. 实际图标、Logo、品牌色和捐赠渠道。
7. 首版是否允许自定义文件名。
8. 第三方组件归属与许可证声明。
